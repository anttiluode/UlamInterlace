Ulam Interlace

Integers wound outward in a square spiral, primes lit, as Ulam doodled them in 1963. Every layer is the same spiral at a different cell size, all centred on the same point, woven together pixel by pixel.

Layers

Cell size is pixels per integer. Click a layer to mute it.

Weave

Spiral

Start at 41 and Euler's n² + n + 41 runs as one long unbroken diagonal.

2 → 3 → 5 → …
0.80 s

Cycle through prime centres 2, 3, 5, 7, 11… up to 1,000,000, then loop. The 1 preset is retained (1 is not prime).

View

Drag to pan, scroll or press + and − to zoom, arrow keys pan. Below 1 px per cell, a pixel shows the prime density of the integers it covers, scaled by ln n, so the diagonals survive zooming out.
